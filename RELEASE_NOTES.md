
# Student Task Manager
## Release Notes – Version 1.0.0

**Release Date:** 24 November 2026

### New Features
- User signup functionality.
- User login functionality.
- Add new tasks.
- Delete existing tasks.
- Mark tasks as complete.
- Save tasks in browser local storage.
- Logout functionality.

### Bug Fixes
- Added validation for empty signup fields.
- Added duplicate email checking.
- Added login credential validation.
- Added task title validation.
- Improved task deletion and completion handling.

### Known Issues
- User accounts are stored in browser local storage.
- Passwords are not securely encrypted.
- Data is not synchronized between different devices.
- Clearing browser storage may remove saved data.
